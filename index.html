PROFILE / 个人简介SIMON / 2019—NOW

把模糊的问题，整理成清晰、可落地的产品体验。

我是 Simon，自 2019 年起持续从事数字产品设计。职业路径从视觉包装与 Web 设计出发，逐步深入消费级 App、复杂 B 端与 Web3 产品，能够根据项目阶段承担用户研究、信息架构、交互、视觉、规范与上线验收等工作。

我既能独立推进完整项目，也能在主管、产品与研发协作中承担明确职责。比起只让页面变得更好看，我更在意设计是否帮助用户做出判断、能否形成可持续的产品语言，以及最终是否被准确实现。
