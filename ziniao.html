01CONTEXT / 项目背景
DESIGN CHALLENGE

不是整理一个后台，
而是建立一套企业控制台。

紫鸟浏览器基于 Chromium 深度开发，为跨境用户提供多平台访问、店铺运营和企业安全能力。随着店铺、IP、账号与成员规模增长，产品需要同时承载更高的信息密度与更严格的操作可信度。

03DESIGN SYSTEM / 可信设计系统

规范不是装饰，
是复杂产品的共同语言。

颜色、间距、字体和基础控件共同降低判断成本；每一种视觉差异都对应真实的层级、状态或风险。

01 / COLOR

#3569FD

04 / BASIC RULES
  • 45%通用遮罩
  • 80%加载遮罩
  • 2px控件圆角
  • 4px弹窗圆角

遮罩、圆角、分割线与阴影都被明确约束，避免不同业务模块自行解释。

04PRODUCT / 关键业务落地

先看状态，
再做决定。

首页将急需续费、待授权、待绑定等异常集中前置，并提供店铺快捷入口；核心管理页沿用同一套筛选、表格与批量操作语言。

02 / WORKSPACE

同一套框架，
适配不同任务。

STORE MANAGEMENT
店铺状态与高频操作

集中查看授权、平台、代理 IP 与风险状态，并在列表内直接完成打开、绑定和续费。

DECISION FLOW
  1. 01识别状态

    异常数字与颜色先被看见

  2. 02缩小范围

    视图、标签与筛选快速定位

  3. 03执行操作

    高频行动直接停留在列表

  4. 04获得反馈

    状态变化与风险提示立即确认

DELIVERED INTERFACES / 实际成果

不仅能切换查看，
关键业务页面也直接完整呈现。

店铺、IP 与安全管理共享同一套导航、筛选、状态和批量操作规则，同时针对各自任务保留不同的信息重点。

05CLIENT EXPERIENCE / 客户端体验

专业工具也需要
有温度的第一分钟。

安装、版本引导与完成反馈被设计成连续体验：解释变化、降低等待感，并明确给出下一步。

INSTALLATION

轻量安装，
明确进入

简化客户端安装路径，减少专业工具给新用户带来的陌生感。

EMOTIONAL FEEDBACK

完成不是终点，
而是下一步入口

完成探索后用轻量插画与单一主行动承接用户，降低等待和切换过程中的不确定感。

06REFLECTION / 项目复盘
WHAT I LEARNED

复杂系统的“简单”，
来自规则足够清楚。

紫鸟浏览器的设计重点不在于减少功能，而在于建立稳定的判断顺序：让状态先于数据、任务先于模块、反馈紧跟行动，并用统一规范支撑持续增长的业务。
