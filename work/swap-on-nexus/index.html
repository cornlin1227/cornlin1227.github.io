ON NEXUS / PRODUCT REDESIGN

BTC 资产交易
界面与体验改版

项目背景

On Nexus 面向 BTC 生态用户，提供代币兑换、流动性与资产管理。这次改版围绕交易流程重新组织入口，同时重构深色界面的视觉层级。

01 / 旧版与改版重点

交易之前
有太多入口需要分辨

旧版将版本、链与协议分布在导航和交易面板中。交互升级方案的重点，是把这些选择放回相应任务，而不是让用户先理解产品结构。

01

入口归位

首页直达 Swap；代币协议放入选币层，账户来源放入支付选择。

02

信息分层

优先呈现兑换信息，行情、池子与交易记录按需展开。

03

视觉重构

用深色层级区分内容，以紫色标识主要操作，减少边框与装饰的干扰。

02 / 兑换与行情

兑换为主，行情按需展开

默认视图保留金额、币种与兑换操作。需要判断价格时，再展开行情与记录；辅助信息增加，不改变交易面板的核心结构。

SWAP / EXPANDED VIEW

03 / 选币与支付

选哪种币
从哪里支付

币种与资金来源是两个不同的选择。选币面板集中展示协议分类与代币信息；支付面板单独区分钱包、Bitcoin Channel 和 V1 账户余额。

不可用余额也要有解释

支付来源不仅显示余额，还区分可用与不可用状态，避免把“有资产”误认为“当前可支付”。

TRADE MODES

三种交易方式
三组关键信息

同一个交易区域，通过页签切换兑换、限价与订单。金额输入保持一致，价格条件和订单选择随任务变化。

Swap

直接兑换

先确定支付与接收资产，再查看汇率、滑点与最低接收数量。

Limit

设置价格条件

目标价格置于金额之前，手续费与有效期集中在操作按钮上方。

Order

选择订单

先选择代币与订单数量，再设置价格并查看预计接收金额。

交易参数集中展开

滑点、最低接收数量与网络费率放在兑换信息下方，与输入金额分层呈现。

05 / 主要界面

行情、流动性与资产

交易之外，延续相同的数据层级与操作样式。用列表承载币种与池子信息，让浏览、持仓查看和后续操作保持连贯。

DESKTOP → MOBILE

资产信息
从横向对照到纵向阅读

账户分类保留，排列方式改变

桌面端用列对齐不同资产的余额；移动端以币种为单位，把 Total、Wallet、Bitcoin Channel 与 Account(V1) 转为纵向字段。

总额之外，单独标出可用余额

可用数量与池内资产采用次级文字，留在对应账户下方，不与总额混为一项。

06 / 移动端

小屏幕上的交易与管理

将高频入口收进底部导航，兑换、池子与资产保持独立路径。桌面的横向信息转为纵向阅读，保留关键数值与操作。
